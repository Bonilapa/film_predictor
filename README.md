# DVD Rental Management

Веб-приложение для управления сетью магазинов проката DVD-дисков на базе учебной базы данных `dvd-rental`.

## Возможности

### Панель магазина

Сотрудник магазина может:

- **Просматривать каталог фильмов** - таблица со всеми фильмами, названием, годом, рейтингом, ценой аренды
- **Добавлять новые фильмы** - форма с названием, описанием, годом выпуска, языком, категориями, ценой
- **Просматривать список клиентов** - таблица с именем, фамилией, email, адресом, телефоном
- **Регистрировать новых клиентов** - форма с автоматическим добавлением адреса (без дубликатов)
- **Выдавать фильмы в аренду** - форма выбора клиента, фильма и сотрудника
- **Принимать возврат фильмов** - таблица активных аренд с кнопкой возврата

### Панель регионального менеджера

Руководитель может:

- **Просматривать дашборд** со сводной статистикой:
  - Общие метрики: всего фильмов, активных аренд, клиентов
  - Выручка за текущий и прошлый месяц
  - Аренды по месяцам (таблица с визуализацией)
  - Топ-10 самых популярных фильмов
  - Выручка по магазинам
- **Смотреть предсказания** - какие фильмы с наибольшей вероятностью возьмут в аренду сегодня:
  - Вероятность для каждого фильма в процентах
  - Доступное количество копий
  - Категория спроса (высокий/средний/низкий)
  - Фильтр по магазину

### ML-предсказания

На основе истории аренд модель машинного обучения предсказывает:

- **Вероятность аренды** конкретного фильма в ближайший день
- **Топ фильмов** с наибольшим ожидаемым спросом

Признаки для модели:
- Частота аренд фильма за последние 30, 60, 90 дней
- Категория и рейтинг фильма
- День недели, месяц (сезонность)
- Количество доступных копий в наличии
